# Camera Shift Mod

[简体中文](README.md) | [繁體中文](README.zh-TW.md) | English

A client-side customization patch for Epic Fight: a smooth camera glide when switching between mining mode and battle mode.

It is already compatible with [Epic Fight - Better Lock On](https://www.curseforge.com/minecraft/mc-mods/better-lock-on) and tuned for it, so it works out of the box :D

(It works fine without that mod installed, too.)

This is a translation of [README.md](README.md); where the versions differ, the Simplified Chinese one prevails.

## Dependencies

- Epic Fight: https://www.curseforge.com/minecraft/mc-mods/epic-fight-mod
