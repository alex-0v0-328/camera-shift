# Camera Shift 相机平滑切换 模组

简体中文 | [繁體中文](README.zh-TW.md) | [English](README.en.md)

Epic Fight的客户端个性化补丁，挖掘模式和战斗模式的平滑相机推拉切换。

并且目前已经针对 [Epic Fight - Better Lock On](https://www.curseforge.com/minecraft/mc-mods/better-lock-on) 进行了兼容，并且进行了调试，开箱即用:D

（如果没有安装以上Mod，也可以正常使用）
